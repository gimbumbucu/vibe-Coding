【 Agent Skills 서비스 안내문 】

안녕하십니까, 고객님. Antigravity IDE의 Agent Skills 기능을 이용해 주셔서 진심으로 감사드립니다.
Agent Skills는 에이전트의 기능을 확장할 수 있는 재사용 가능한 지식 패키지로, SKILL.md 파일 하나로 손쉽게 생성하실 수 있습니다.
워크스페이스 전용 스킬(.agents/skills/)과 전체 프로젝트에 적용 가능한 글로벌 스킬(~/.gemini/antigravity/skills/)을 모두 지원해 드리고 있습니다.
에이전트는 대화 시작 시 사용 가능한 스킬 목록을 자동으로 파악하며, 작업 맥락에 따라 적절한 스킬을 스스로 선택하여 활용합니다.
보다 자세한 내용은 공식 문서를 참고해 주시면 감사하겠습니다.
