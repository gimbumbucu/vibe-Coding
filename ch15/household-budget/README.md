# 📊 Google Apps Script + Clasp 스마트 가계부 & 자산관리 시스템

**Google Apps Script (GAS) API**, **Clasp (TypeScript)**, **Google Sheets (구글 스프레드시트)**, **Google Drive (구글 드라이브)**를 연동하여 구축된 올인원 자동화 가계부 시스템입니다.

---

## ✨ 핵심 기능

1. **📊 실시간 대시보드 및 시각화**
   - 당월 총 수입 / 총 지출 / 순 잔여금 / 예산 소진율 KPI 카드
   - 카테고리별 지출 비중 도넛 차트 및 추이 분석
   - 계좌별 실시간 잔액 및 자산 총액 자동 집계 (`SUMIFS` 수식 연동)

2. **📝 직관적인 사이드바 입력 폼 (HTML / CSS / JS)**
   - 지출 / 수입 / 이체 원터치 탭 전환
   - 빠른 금액 입력 버튼 (+1만, +5만, +10만) 및 천 단위 자동 콤마
   - 대분류 선택 시 소분류 동적 필터링
   - **구글 드라이브 영수증 첨부**: 영수증 사진/PDF 업로드 시 `가계부_보관함/영수증/YYYY-MM` 폴더에 자동 저장 및 시트에 열기 링크 매핑

3. **🎯 예산 한도 관리 & 경고 알림**
   - 카테고리별 월간 예산 설정 및 실시간 소진율(%) 계산
   - 예산 초과(100% 이상) 또는 주의(80% 이상) 시 상태 뱃지 표시 및 **Gmail 경고 이메일 자동 발송**

4. **🔄 고정비 자동 등록 (시간 기반 트리거)**
   - 월세, 관리비, 통신비, 구독료 등 고정비를 등록해두면 **매월 1일 오전 6시에 당월 거래내역으로 자동 등록**

5. **📑 월간 결산 보고서 & 자동 백업 (Drive & Gmail)**
   - **매월 말일** 당월 대시보드를 **PDF 보고서로 자동 변환**하여 구글 드라이브 `백업_보고서` 폴더에 보관
   - 당월 거래내역을 **CSV 파일로 백업**하고 요약 리포트를 Gmail로 자동 전송

6. **⚙️ 원클릭 자동 초기화 (Setup)**
   - 새 빈 스프레드시트에서 메뉴 클릭 한 번으로 모든 시트(대시보드, 거래내역, 예산, 계좌, 고정비, 설정), 서식, 색상, 수식, 드라이브 폴더 일괄 자동 생성

## 📁 프로젝트 구조

```
household-budget/
├── .clasp.json               # Clasp 프로젝트 설정 (scriptId, rootDir)
├── .claspignore             # clasp push 대상 제외 설정
├── appsscript.json          # Apps Script 매니페스트 (권한 스코프 및 런타임 V8)
├── package.json             # 프로젝트 메타데이터 및 의존성
├── tsconfig.json            # TypeScript 컴파일러 설정
├── README.md                # 사용 설명서
└── src/
    ├── main.ts              # GAS 전역 진입점 (onOpen 메뉴, API 핸들러, 트리거 함수)
    ├── config.ts            # 시스템 상수, 시트명, 기본 카테고리/계좌 데이터
    ├── models/
    │   └── types.ts         # 트랜잭션, 계좌, 예산, 고정비 TypeScript 타입 정의
    ├── services/
    │   ├── sheetService.ts  # 시트 생성, 서식, 수식, 유효성 검사, 거래 기록 엔진
    │   ├── driveService.ts  # Drive 폴더 생성, 영수증 업로드, PDF/CSV 백업 내보내기
    │   ├── budgetService.ts # 예산 소진율 집계 및 이메일 경고 발송
    │   └── triggerService.ts# 고정비 자동 등록, 월간 결산 및 정기 트리거 설치
    └── ui/
        ├── sidebar.html     # 사이드바 입력 폼 UI 마크업
        ├── sidebar.css.html # 모던 글래스모피즘 스타일시트
        └── sidebar.js.html  # 폼 검증, Base64 영수증 인코딩, google.script.run 통신
```

## 🚀 빠른 시작 가이드 (Clasp 배포 방법)

### 1단계: 패키지 설치
```bash
npm install
```

### 2단계: Google 계정 로그인 (Clasp)
```bash
npx clasp login
```
> 브라우저가 열리면 Google 스프레드시트 및 드라이브를 사용할 구글 계정으로 로그인하고 권한을 허용합니다.

> 💡 **주의**: Google Apps Script API가 활성화되어 있어야 합니다.  
> [Google Apps Script 사용자 설정](https://script.google.com/home/usersettings)으로 이동하여 **"Google Apps Script API"를 ON**으로 변경하세요.

---

### 3단계: 가계부 프로젝트 생성 및 스프레드시트 바인딩

#### 방법 A) 새 구글 스프레드시트를 만들면서 바인딩할 경우 (추천):
```bash
npx clasp create --type sheets --title "스마트 가계부" --rootDir ./src
```
- 생성이 완료되면 `.clasp.json` 파일에 `scriptId`가 자동으로 채워집니다.

#### 방법 B) 이미 생성된 구글 스프레드시트에 연결할 경우:
1. 구글 스프레드시트를 열고 상단 메뉴의 **[확장 프로그램] > [Apps Script]**를 클릭합니다.
2. Apps Script 편집기 좌측 **[프로젝트 설정 ⚙️]**으로 이동하여 **스크립트 ID (Script ID)**를 복사합니다.
3. 로컬 프로젝트의 `.clasp.json` 파일을 열고 복사한 ID를 입력합니다:
   ```json
   {
     "scriptId": "여기에_복사한_스크립트_ID_입력",
     "rootDir": "./src"
   }
   ```

---

### 4단계: 소스코드 Google Apps Script로 업로드 (Push)
```bash
npm run push
# 또는
npx clasp push
```

---

### 5단계: 스프레드시트 열기 & 최초 권한 승인 / 초기 세팅
1. 터미널에서 다음 명령어로 스프레드시트를 엽니다:
   ```bash
   npx clasp open
   ```
2. 스프레드시트 상단 메뉴에 **`📊 스마트 가계부`** 메뉴가 표시됩니다.  
   *(안 보일 경우 페이지를 새로고침 F5 하세요)*
3. **`📊 스마트 가계부` > `⚙️ 가계부 초기 세팅`**을 클릭합니다.
4. Google 권한 승인 팝업이 뜨면 **[계속] > [고급] > [스마트 가계부(안전하지 않음)으로 이동] > [허용]**을 차례로 클릭합니다.
5. 초기화가 완료되면 **대시보드, 거래내역, 예산관리, 자산계좌, 고정비관리, 설정** 시트가 자동으로 완성됩니다!

---

### 6단계: 자동화 트리거 설치
스프레드시트 상단 메뉴에서 **`📊 스마트 가계부` > `⏰ 자동화 트리거 설치`**를 클릭합니다.
- 매월 1일 고정비 자동 입력 트리거 활성화
- 매월 말일 월간 결산 PDF 백업 및 이메일 발송 트리거 활성화

---

## 📱 사용 방법

### 1. 거래내역 입력하기
1. **`📊 스마트 가계부` > `📝 내역 입력 사이드바 열기`** 클릭
2. 지출/수입/이체 선택 -> 금액, 내용, 카테고리, 계좌 선택
3. 영수증이 있을 경우 카메라 촬영 또는 이미지 파일 첨부 (드라이브에 자동 보관)
4. **`➕ 거래내역 등록`** 클릭 -> 실시간 시트 반영 및 잔액/예산 자동 계산!

### 2. 고정비 관리
- `🔄 고정비관리` 시트에서 월세, 구독료, 공과금 등을 행으로 추가하고 활성화여부를 `Y`로 설정해두면 매월 1일 자동 반영됩니다.

### 3. 예산 관리
- `🎯 예산관리` 시트에서 카테고리별 당월 목표 예산을 설정합니다.
- 지출이 예산의 80%에 도달하면 `⚠️ 주의`, 100% 이상 초과 시 `🚨 초과`로 자동 변경되며 경고 이메일이 발송됩니다.

## 🛠 유용한 Clasp 명령어

| 명령어 | 설명 |
|---|---|
| `npm run typecheck` | TypeScript 정적 타입 검사 (`tsc --noEmit`) |
| `npm run push` | 로컬 코드를 Google Apps Script로 업로드 |
| `npm run watch` | 파일 수정 시 실시간 자동 push |
| `npm run open` | 브라우저에서 Apps Script 편집기 또는 시트 열기 |
| `npm run logs` | Apps Script 실행 로그 실시간 확인 |
