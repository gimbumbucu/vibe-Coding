# 네이버 서버 시간 기반 예약 클릭 매크로 (Naver Server Time Macro)

네이버 서버 시간(`time.naver.com` 등)과 정확하게 동기화하여, 사용자가 지정한 찰나의 시간에 화면 상의 3개의 좌표를 지연 없이 동시에(연속적으로) 클릭하는 파이썬 기반 GUI 자동화 프로그램입니다. 주로 수강신청, 티켓팅 등 0.1초 단위의 정밀한 타이밍이 요구되는 작업에 활용하기 위해 제작되었습니다.

## 주요 기능
- **직관적인 GUI (Tkinter)**: 사용하기 쉬운 윈도우 그래픽 인터페이스 제공.
- **정밀한 시간 동기화**: 백그라운드 스레드에서 네이버 서버(`https://www.naver.com`)에 HTTP HEAD 요청을 보내 `Date` 응답 헤더를 주기적으로 파싱하여 로컬 PC와의 시간 오차를 보정합니다.
- **간편한 마우스 좌표 획득**: 전역 마우스 후킹(`pynput`)을 활용하여 설정 버튼을 누른 뒤 화면 원하는 곳을 직접 '좌클릭'하기만 하면 자동으로 좌표가 저장됩니다.
- **초고속 연속 클릭**: 목표 시간 도달 시 `pyautogui`를 이용하여 지연 시간(Delay) 없이 3개의 좌표를 순식간에 클릭합니다. CPU 점유율 최적화를 위한 스마트 슬립(Smart Sleep)이 적용되어 있습니다.

## 실행 환경 및 사전 준비

이 프로젝트는 파이썬 패키지 관리자인 `uv`를 사용하도록 설정되어 있습니다. 파이썬 환경이 없다면 `uv`를 설치해 주세요.

### 의존성 라이브러리
- `requests` (서버 시간 파싱)
- `pyautogui` (자동 마우스 클릭)
- `pynput` (전역 마우스 이벤트 감지)

## 실행 방법

터미널(명령 프롬프트)을 열고 프로젝트 폴더로 이동한 후, `uv run` 명령어를 통해 스크립트를 실행합니다. 

```bash
uv run python naver_macro_gui.py
```

### 프로그램 사용 순서
1. 프로그램이 실행되면 상단에 실시간으로 보정된 **[네이버 시간]**이 표시됩니다.
2. 중간의 **[클릭 좌표 설정]** 영역에서 각 번호의 `[좌표 설정]` 버튼을 차례대로 누릅니다.
3. 버튼을 누른 뒤, 실제 화면에서 클릭하길 원하는 위치에 마우스를 올리고 **왼쪽 버튼을 클릭**합니다. (X, Y 좌표가 자동으로 기록됩니다.)
4. 1~3번 타겟 좌표를 모두 지정합니다.
5. **[목표 시간 설정]** 영역에 매크로가 작동할 24시간제 시각(HH : MM : SS)을 정확히 입력합니다.
6. 하단의 초록색 **[매크로 시작]** 버튼을 누릅니다.
7. 매크로는 백그라운드에서 시간을 감시하다가, 네이버 서버 시간이 목표 시간과 일치하는 순간 지정한 3곳을 순식간에 클릭하고 종료됩니다.

## 테스트 방법 (test_page.html)

매크로가 정상적으로 동작하는지, 오차 없이 3번의 클릭이 연속적으로 이루어지는지 안전하게 테스트하기 위해 포함된 `test_page.html`을 활용합니다.

1. 웹 브라우저(크롬, 엣지 등)에서 프로젝트 폴더 내의 `test_page.html` 파일을 엽니다.
2. 매크로 프로그램을 실행(`uv run python naver_macro_gui.py`)합니다.
3. 매크로 프로그램의 `좌표 설정` 기능을 사용하여 브라우저에 띄워진 **[1번 타겟], [2번 타겟], [3번 타겟]** 버튼 정중앙을 각각 좌클릭하여 매핑합니다.
4. 매크로의 목표 시간을 현재 네이버 시간의 약 20~30초 뒤로 설정하고 시작합니다.
5. 마우스에서 손을 떼고 기다립니다.
6. 정해진 시간이 되면 매크로가 화면 상의 타겟 버튼 3개를 자동으로 누릅니다.
7. HTML 페이지 하단의 **[클릭 모니터링 로그]** 패널에서 버튼들이 몇 시 몇 분 몇 초 (밀리초 포함)에 눌렸는지 기록을 확인하여 정확도를 검증합니다.
